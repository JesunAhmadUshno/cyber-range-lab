# cyber-range-lab

**Question.** Can a small, defensive-only hardening checker and
detection loop turn one isolated lab VM's configuration and logs into
a hardening score, deduplicated alerts and a closed incident record
that a second person can reproduce?

**Headline.** Exploratory, not pre-registered, and on synthetic data only: on 26 hand-written log lines and three hand-written snapshots of one simulated lab VM, the loop parses 24 lines (2 quarantined), turns 9 rule firings into 6 alerts, flags drift on 2 of 10 hardening controls and walks one incident to closed, and the brute-force rule separates the authored 6-failure burst from a 4-failure near miss only at thresholds 5 and 6 of 1 to 10; no interval applies (deterministic counts on one fixed corpus), and no real machine has been read.

**Field.** Systems and infrastructure, reliability. **Job family.**
Security engineering (hardening, detection and incident response,
defensive). Scope: defensive only; scenario work stays held behind the
Owner's sign-off per scenario, and no verdict depends on running one.

**Verdict.** Draft, not pre-registered. The code and tests are real,
CI passes on Python 3.11 and 3.12, and one command regenerates every
results file byte for byte from experiments/, but the system under
study, a hardening and detection loop on a lab VM, has only ever read
hand-written snapshots and logs, never a real machine, so Functional
is not met. No plan with hypotheses and pass lines was committed before
the results, so Proposed is not met either. Functional needs one
read-only defensive capture from a real lab VM (REPORT.md).

Live dashboard: https://jesunahmadushno.github.io/cyber-range-lab/ (the
loop running in your browser on the repo's synthetic inputs; the build
fails unless the browser port reproduces every results file).

Project: P24. Fleet node: Dell R610 (not yet used; every run so far was
on the Muse VM).

## Reproduce

```text
python3 src/run_deep.py && python3 src/evaluate_deep.py && git diff --exit-code results/
python3 -m unittest discover -s tests -p "test_*.py" -v
cd site && npm ci && npm run build
```

Python 3 standard library only; Node 22 for the dashboard.
`src/run_learn.py` and `src/run_build.py` re-run the hardening checker
and the detection loop on their own. Every headline number traces to
results/results_deep.json or results/results_eval.json; REPORT.md lists
which command prints which number.
